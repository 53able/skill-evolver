言語: [English](../../experiments/report-001.md) | 日本語

決定論的なモックモデルは、公開された `uppercase` 操作を実際のDockerツールで実行します。この結果は、ワークフローの実行と再開時の動作を確認するものです。スキルの品質やGAの有効性を測定するには、実モデルによる別の実験が必要です。この検証では、実際の有料モデル呼び出しを行っていません。

## 検証

```sh
SKILL_EVOLVER_DOCKER_TESTS=1 PYTHONPATH=src uv run --locked python -m unittest discover -s tests -q
uv tool run --from ruff==0.14.14 ruff check --select F,E9 src tests _build_backend.py
uv tool run --from mypy==1.19.1 mypy --check-untyped-defs --ignore-missing-imports src/skill_evolver
```

Docker統合テストを含む73件のテストが、スキップなしですべて成功しました。Ruffは成功し、mypyもソースの全14モジュールで成功しました。テストは、識別子の衝突、ランタイムの固定、ストレージとプロセスの制限、対象を厳密に特定したリソース復旧、フェーズの分離、中断された呼び出し、既知・不明の使用量、条件付き比較のレポートを対象にしています。使用量が不明な場合は、停止やクリーンアップも失敗し、後続の試行が成功したとしても、未完了のままです。

`uv sync --locked`、CLIによる検証、`uv pip` による通常のwheelインストール、インストール後のコンソールコマンドも成功しました。

## 制約

実際のOpenAIとの互換性と、実モデルによるスキルの改善は未検証です。HTTPと提案のテストには、モック化した通信処理または注入したブローカーを使っています。有料実験の前に、プロバイダーの価格に基づいてトークン単価を設定し、トークン数カウントのリクエスト料金を別途確認してください。台帳は設定された単価で集計します。

データセットを分割する前に、関連する評価ケースをグループ化してください。改善の判定には、独立した最終評価グループが10以上必要です。スキルに同梱されたローカルアセットは未対応です。イメージIDが固定されていない過去の実行は、現在の有効な実験として再開できません。
