# クイックガイド: 自分のスキルを1回改善してみる

言語: [English](../quick-guide.md) | 日本語

このガイドは、自作スキルの出力に不満があり、まず1回試してみたい人向けです。読み終えると、評価案を自分で判断し、結果を見て改善版を採用するかどうか決められます。仕様の詳細は [README](README.md) にあります。

## 対象になるスキル

- **対象:** 応答をテキストとして評価できる `SKILL.md`（64 KiB以下）。`references/`・`assets/` などの補助ファイルは読み取り専用で使います。
- **対象外:** スクリプトの実行、ブラウザ、外部サービスが目的に欠かせないスキル。`prepare` の時点で止まります。
- **改善されないもの:** frontmatter（`name`／`description`）と、スキルが呼び出されるかどうか。

## 1. 準備（5分）

```sh
uv tool install /path/to/skill-evolver   # 見つからない場合は uv tool update-shell を実行し、シェルを開き直す
mkdir -p ~/.claude/skills && cp -R /path/to/skill-evolver/skills/improve-skill ~/.claude/skills/
```

`claude`（または `codex`）に普段どおりログインしておきます。APIキーは不要です。Codexで使う場合は、コピー先を `~/.codex/skills/` にします。

## 2. エージェントに頼む

新しい会話で、次のように頼みます。

> `~/.claude/skills/my-skill/SKILL.md` を improve-skill で改善して

使うモデルを聞かれたら答えます（例: `sonnet`）。2分ほどで評価案ができ、エージェントが要約を見せます。

## 3. 評価案を判断する（ここが本番）

改善したかどうかは、この評価案だけで判定します。承認する前に `evaluation.md` を読み、次の4点を確認します。

1. 課題が、そのスキルの実際の使い方に近いか
2. 必須（required）の基準が本当に重要な点か。甘すぎたり、達成不可能だったりしないか
3. 今のスキルがすでに全基準を満たしそうではないか。満たしそうなら改善は示せないため、実際にうまくいかなかった依頼で課題を1件差し替えるよう頼みます
4. 最終確認用の課題が、改善用の課題と実質的に同じになっていないか

問題がなければ「承認」と答えます。直したい点はそのまま会話で伝えれば、エージェントが `evaluation.json` を編集し、もう一度承認を求めます。

## 4. 待つ（数分〜最大1時間）

承認後、エージェントがバックグラウンドで実行します。モデル呼び出しは45回前後で、上限は60回です。終わったら「結果を確認して」と頼みます。

## 5. 結果を読む

| 結果 | 意味 | 次にすること |
| --- | --- | --- |
| `observed_improvement` | 最終確認用の課題で得点が上がり、必須基準に新しい失敗がない | 差分を読み、納得したら採用を頼む（元のファイルはバックアップされる） |
| `no_observed_improvement` | 改善を確認できなかった。元のスキルは変更されない | 得点の内訳を見る。評価が易しすぎたなら、課題を難しくして新しく準備する |
| `incomplete` | 評価が終わらなかった | 理由を確認し、新しい保存先で準備し直す |

課題は改善用・最終確認用とも3件だけで、作成も採点もモデルが行います。`observed_improvement` は「この評価では良くなった」という観測で、一般的に優れていることの証明ではありません。差分は必ず自分で読んでください。

## つまずいたとき

- **`skill-evolver` が見つからない:** `uv tool update-shell` を実行し、新しいシェルで開き直します。
- **`unsupported_cli_version` で止まる:** 検証済みのCLIバージョンではありません。試す場合は、新しい保存先で `--allow-untested-cli` を付けて準備し直します。
- **Codexでネットワークにつながらない:** 既定のサンドボックスが原因です。エージェントがサンドボックス外での実行を求めたら、内容を確認して許可します。
- **途中で止まった・失敗した:** 再開はできません。新しい保存先で `prepare` からやり直します。

## エージェントを使わずに実行する

```sh
skill-evolver improve prepare ~/.claude/skills/my-skill/SKILL.md \
  --provider claude --model sonnet --output ~/skill-evolver-runs/my-skill-$(date +%Y%m%d-%H%M%S)
skill-evolver improve run ~/skill-evolver-runs/my-skill-20261025-120000   # 表示された保存先を指定し、y で実行
```

`run` の実行中は端末を閉じないでください。各コマンドが、次に打つコマンドを表示します。
